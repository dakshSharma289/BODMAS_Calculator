# BODMAS_Calculator
This is Terminal Calculator app in c++ which can perform BODMAS operations.

Test Expressions: 
  $$(((4+5)x2)-6)/(4/2)=6$$
  $$((10+(5x2))/4)x(6-(3+1))=10$$
  $$(((12/3)+8)x2)-(4x(5-1))=8$$
  $$((18/(3x2))+(7-2))x(12/(2+4))=16$$
  $$((24/(4+2))x4)/((9-5)x2)=2$$

Syntax: 
  No spaces
  only paranthesis
  divide operator is /
  multiplication operator is x
  there is no "off" operation

There is no quit command, instead the program runs for 10 iterations and then stops.
