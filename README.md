# BODMAS_Calculator <br>
This is Terminal Calculator app in c++ which can perform BODMAS operations. <br>
<br>
Test Expressions: <br>
  $$(((4+5)x2)-6)/(4/2)=6$$ <br>
  $$((10+(5x2))/4)x(6-(3+1))=10$$ <br>
  $$(((12/3)+8)x2)-(4x(5-1))=8$$ <br>
  $$((18/(3x2))+(7-2))x(12/(2+4))=16$$ <br>
  $$((24/(4+2))x4)/((9-5)x2)=2$$ <br>
<br>
Syntax: <br>
  No spaces <br>
  only paranthesis <br>
  divide operator is /  <br>
  multiplication operator is x <br>
  there is no "off" operation <br>
 <br>
There is no quit command, instead the program runs for 10 iterations and then stops.  <br>
