# BODMAS_Calculator /n
This is Terminal Calculator app in c++ which can perform BODMAS operations. /n
/n
Test Expressions: /n
  $$(((4+5)x2)-6)/(4/2)=6$$ /n
  $$((10+(5x2))/4)x(6-(3+1))=10$$ /n
  $$(((12/3)+8)x2)-(4x(5-1))=8$$ /n
  $$((18/(3x2))+(7-2))x(12/(2+4))=16$$ /n
  $$((24/(4+2))x4)/((9-5)x2)=2$$ /n
/n
Syntax: /n 
  No spaces /n
  only paranthesis /n
  divide operator is /  /n
  multiplication operator is x /n
  there is no "off" operation /n
 /n
There is no quit command, instead the program runs for 10 iterations and then stops.  /n
